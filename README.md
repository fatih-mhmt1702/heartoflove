## ✨ Özellikler

- **100 Dilde Kalp Animasyonu:** Parametrik kalp denklemi ile oluşturulmuş, çift vuruşlu nabız ritmiyle atan ve fare hareketlerine tepki veren akıcı kalp motoru.
- **İki Farklı Görünüm Modu:**
  - *Hatları Çiz:* Kalbin dış çeperinin yandığı kontur görünümü.
  - *Kalbi Doldur:* Kalbin içinin de sevgi sözcükleriyle dolduğu tam görünüm.
- **Sıcak Renk Paleti:** Derin kadife tonları, neon aşk kırmızısı, alev mercanı ve kehribar altın ışıltıları.
- **3D Mühürlü Aşk Mektubu:** Mührüne dokunulduğunda 3D açılan zarf ve süzülen özel mektup.
- **Romantik Ambiyans Melodisi:** Web Audio API ile sıfır dış bağımlılıkla tarayıcıda çalınan kristal piyano arpejleri.
- **Etkileşimli Kartlar & Söz Üreteci:** "Neden Sen?" kartları ve canlı aşk sözleri.

---

## 🚀 Başlangıç

Projeyi çalıştırmak için:
1. Repoyu klonlayın veya indirin.
2. `index.html` dosyasına çift tıklayarak doğrudan tarayıcınızda açın ya da `baslat.bat` dosyasını çalıştırın.
3. Alternatif olarak yerel sunucu ile:
   ```bash
   node server.js
   ```
   Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine gidin.
